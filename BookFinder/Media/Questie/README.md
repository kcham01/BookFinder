# Questie's icons

These icon files are from **Questie** (https://github.com/Questie/Questie, version 12.9.0), shipped in BookFinder at
the owner's request so quests look the way Questie draws them. Questie's own note on them: their licensing "is
unclear, please consider them all rights reserved", except `slay_mono.tga`, `loot_mono.tga`, `object_mono.tga` and
`node.tga`, which come from pfQuest (https://github.com/shagu/pfQuest) under the MIT licence (`MIT.txt`). Credit to
Questie's and pfQuest's authors. Questie's name and logo are not used by BookFinder.
